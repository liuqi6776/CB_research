# 新闻情绪温度计：辅助指数增强择时（设计）

> 来源: 本项目 quant_conclusion 延伸研究（iFinD MCP 数据实测，2026-08-01）
> 关联已确认结论: [新闻情感与股价预测](./news_sentiment_prediction.md)（T+2 最佳窗口、负面预测力 1.5 倍、DOS 预测波动）；[风格中性化指数增强](./style_neutralized_index_enhancement.md)（MA20 三档仓位 100/50/0）
> 验证方式: iFinD `search_news` 实测市场新闻流可日拉（2026-07-29 ~ 07-31）
> 状态: 方法设计 ⚠️ 未验证（待回测确认择时增益）

## 动机

已确认研究证明：① 新闻影响需 1-2 天释放（T+2 最佳）；② 负面情感预测力 ≈ 正面 1.5 倍；③ 情感分歧度 DOS 预测**波动**而非方向。指数增强的 MA20 三档风控是纯价格信号，**没有情绪维度**——极端恐慌/亢奋往往领先于均线破位。用 iFinD 每日新闻流构建"情绪温度计"，作为 MA20 择时的辅助降仓信号。

## iFinD 数据实测（2026-07-29 ~ 07-30 市场情绪样本）

`search_news` 返回标题+内容片段+日期+URL，可直接做情感打分。实测窗口恰好是情绪剧烈波动的两天：

| 日期 | 关键信息（新闻摘要） | 情绪判读 |
|------|---------------------|---------|
| 07-29 | 探底回升，4200 只上涨，创业板指 +1.55%，消费/教育领涨，半导体调整 | 中性偏修复 |
| 07-30 | 沪指 -0.62%、创业板指 -3.97%、科创综指 -5.70%；半导体产业链跌停潮（通富微电、雅克科技等近 10 只触跌停）；中际旭创成交 597 亿天量 | **强负面 + 高分歧** |

- 07-29 → 07-30 由修复急转为强负面，且成交放量（2.3 万亿+）→ 典型"高 DOS 高波动"日，按已确认研究应用 **波动率预测**：降仓/观望。
- 与指数数据交叉验证：中证1000 7/31 收盘 7075.5 < MA20 7531.1 → 价格风控也已触发 0 仓位档。**情绪温度计与 MA20 在此窗口给出同向信号**（交叉确认，非新增矛盾）。

## 情绪温度计设计

```
每日流程（盘后）:
1. search_news 拉当日市场新闻 N 条（标题+内容片段）
2. 情感打分: 负面词加权（否定词反转、程度词、转折降权）→ 沿用已确认研究的 LLM 精细情感方法
3. 聚合: 市场情绪分 S = mean(单条得分)；分歧度 DOS = std(单条得分)
4. 输出信号（叠加到 MA20 三档）:
   - MA20 之上 & S 正常 → 维持原档位（100/50）
   - MA20 之上 & DOS 高（>历史 80 分位）或 S 骤降 → 降一档
   - MA20 之下 → 0 仓位（原规则优先，情绪仅作确认）
5. 冷却规则: 单日信号不改档，需连续 2 日同向才触发（避免新闻噪声）
```

## 关键设计要点

1. **T+2 窗口落地**：当日情绪信号用于 T+2 仓位调整，与已确认的"新闻影响 1-2 天释放"一致。
2. **负面不对称**：只把**强负面/高分歧**当作降仓触发器，正面信号不追高（负面预测力 1.5 倍，正面信号可信度低）。
3. **DOS 只预测波动**：高 DOS 时即使方向不明，也先降仓（波动加大 → 风险预算收缩）。
4. **与 MA20 的关系**：情绪温度计是 MA20 的**先行确认**，不是替代——避免在均线金叉早期被单一情绪信号反复打脸。

## 避坑清单

- ⚠️ 新闻流存在明显情绪周期（恐慌/亢奋切换快），单日信号噪声大，必须用连续 2 日 + 分位数阈值过滤。
- ⚠️ 公司名匹配精度有限（已确认研究已指出），本设计只做**市场级**情绪聚合，不做个股级匹配，规避该缺陷。
- ⚠️ 结论基于 2024-10 ~ 2025-02 区间验证，新闻环境变化后需重新校准阈值。
- ⚠️ 该模块只能**降仓避险**，不能提升选股 alpha——定位为风控增强而非收益来源。
