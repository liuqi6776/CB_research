    二、证监会将就稳市场召开专题座谈会

    证监会将于7月20日召开上市公司、证券公司及基金机构座谈会，听取各方关于促进资本市场平稳健康发展的意见建议。

    中国国新：已使用股票回购增持专项再贷款及配套资金超500亿元，用于维护市场稳定。

    中国诚通：大额增持中国股票资产，累计买入近百亿元。

    中国国新和中国诚通曾在2025年4月7日晚发布增持信息，随后A股进入长达1年多的上涨行情。

    金融：湘财股份、国盛证券、汇金科技、银之杰、赢时胜、同花顺

    北交所+金融：艾融软件、联迪信息、华信永道

     

     

     

     

     

    三、长飞光纤总裁庄丹：未来一两年保偏光纤需求增长在10倍甚至20倍级

    长飞光纤执行董事兼总裁庄丹在2026世界人工智能大会“曦智科技·光计算与光互连双轮驱动的AI基础设施新范式论坛”上提出，全球光纤市场需求已由电信驱动转向智算中心驱动，预计到2030年，全球FTTx（光纤通信网络）的年复合增长率为2.47%，而智算中心的年复合增长率将达到20.74%。“保偏光纤以其卓越的稳定性，正成为CPO硅光时代的最佳连接介质。”庄丹表示。同时他预判，受新一代高性能CPU、硅光光组件拉动，未来1-2年保偏光纤需求（增长）在10倍甚至20倍级。

    光纤：长飞光纤、中天科技、亨通光电、远东股份、特发信息

     

    四、茅台涨价

    贵州茅台公告称，公司自2026年7月18日零时起，将飞天53%vol500ml贵州茅台酒(2026)i茅台平台零售价由1539元/瓶调整为1639元/瓶，销售合同价由1269元/瓶调整为1369元/瓶。

    白酒：贵州茅台、五粮液、舍得酒业、酒鬼酒、古井贡酒、水井坊

     

    五、央视财经：钼铁一天跳涨1500元 工业维生素钼迎来长期利好

    钼被称为“工业维生素”，今年上半年，国内钼市场行情持续走强。钼精矿经冶炼加工产出的钼铁一吨一天上涨1500元，上半年钼铁价格累计涨幅已接近三成。目前，国内超过七成的钼需求，来自特种钢材领域。随着我国新能源产业加速迭代、高端装备制造业持续转型升级，含钼特钢的需求持续放量。数据显示，2026年上半年国内钢厂钼铁招标总量8.2万吨，同比提升6%。同时，新型显示、钙钛矿光伏、半导体等新兴赛道的技术迭代，也为钼产业打开了全新的增量空间，推动钼市场从工业刚需向高端新材料领域升级。

    钼：盛龙股份、金钼股份、洛阳钼业、国城矿业

     

    六、行业要闻

    1、Kimi K3登顶Frontend Code Arena全球AI大模型榜单；算力紧缺，暂停C端新用户订阅；月之暗面已向投资人发送上市议案，预计最快六个月内在港IPO。（九安医疗、米奥会展）

    7、中国电信董事长柯瑞文：将适度超前建设算力基础设施。

    8、央视财经：投资中国AI产业链成全球共识，中国AI科技零部件订单排至2027年底。
