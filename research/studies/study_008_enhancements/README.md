## 方向1：北向资金 + 两融余额信号（❌ 无效）

**信号构造**（均 T-1 生效）：
- 两融预警：全市场融资余额（SSE+SZSE+BSE 合并）20 日变化率 < 0 → 覆盖率 **40.8%**
- 北向预警：北向资金 20 日累计净买额 < 0（2020-01~2024-08 有效，2024-08 起停止披露）→ 覆盖率 **33.9%**
- 叠加规则：预警时 MA20 仓位 ×0.5

**结果**：
- 全区间：+MA20+两融 = 13.89%（vs MA20 15.72%），MaxDD 仅降 0.14pp，卡玛 0.87→0.77
- 北向子区间：+MA20+北向 = 11.72%（vs 13.54%），MaxDD 降 1.4pp，卡玛 0.88→0.84

**失效原因**：预警覆盖率过高（34-41%）→ 频繁半仓 → 踏空损失（-1.8~-2.0pp）远大于回撤节省（-0.1~-1.4pp）。两融余额下降在牛市中常见（去杠杆回调），北向流出滞后于 MA20 交叉；信号预测力弱于现有 MA20 本身。

## 方向2：层次风险平价 HRP（✅ 温和正增量）

**方法**：调仓日取截至 rb 的过去 120 日个股收益 → LedoitWolf 收缩协方差 → 单连接层次聚类 → 递归二分风险分配（簇间按逆波动率加权）→ 叶子权重。月内固定，与等权同口径（20bps、RS12、MA20）。

**结果**：
- HRP = 15.00% / 0.81 / -18.37% / 卡玛 **0.82**（等权 0.76）
- HRP+MA20 = 15.58% / 0.93 / **-17.34%** / 卡玛 **0.90**（等权+MA20 为 0.87）

**解释**：HRP 利用个股相关性结构，降低高相关簇（同行业/同风格股）的实际集中度；等权组合在行业集中时暴露系统性风险，HRP 无优化目标、无过拟合风险。增量温和但方向正确：收益持平、回撤 -0.7~-1.1pp、卡玛 +0.03~0.06。

### 方向A：主力资金流因子（❌）
mf20 = 过去20日超大单净流入累计 / 同期(超大单+大单)成交额累计，加入五因子选股。月度成分重叠率 66.1%——资金流与现有 ret_1m/换手率量价因子高度重叠，加入后稀释因子纯度：收益 -0.5pp、卡玛 -0.01（带 MA20）。iFinD 侧"主力净流入"概念存在（get_stock_performance 可查），本地 moneyflow1 数据质量优秀（可用率 99.8%+），但**无增量信息**。

### 方向B：宏观 PMI 择时（❌）
iFinD EDB 制造业 PMI 完整月度（2020-01~2026-06），调仓月取上月已发布值（shift(1) 无前视），弱态时 MA20 仓位×0.5。三种弱态定义（PMI<49 / 连续2月<50 / 3MA<50，覆盖率 6%/33%/64%）全部负增量：收益损失 -1.3~-3.9pp 大于回撤节省（极端态还反升 +1.5pp）。与方向1（两融/北向）失败模式完全一致——**MA20 已是有效趋势过滤，任何额外宏观/资金面减仓都是多余，造成踏空**。

### 方向C：质量因子 QMJ（❌ 数据不足 + 负增量）

### 3.12 实盘改造阶段 3（2026-08-04，P0-2）：双账本 + 订单状态机

新增 `ledger.py`（可成交执行层，与冻结基线 `engine.py` 平行运行，不改基线口径）：

- **双账本**：`target_weight`（月末 IVW120 目标权重）/ `actual_weight`（T 日开盘成交、份额持有、期间随价格漂移）/ `cash_weight` / `pending_orders` / `tracking_error`。
- **订单状态机**：`NEW → FILLED / BLOCKED(顺延) / DROPPED(目标退出)`。核心规则（用户验收 P0-2）：**"买不进 → 现金保留；卖不出 → 旧仓继续承担收益风险，不现金化"**。
- **阻塞判定**：买入侧 ST / 一字涨停 / 停牌；卖出侧停牌 / 一字跌停。成本仅计实际执行换手（未成交零成本）。
- **fail-closed 补强**：信号缺失（`picks is None`）→ 沿用上期持仓；**目标腿（512100）无行情 → 整期不调仓沿用旧仓**（旧实现会卖出股票后买不进 ETF 全现金化，违反 P0-4，已修复）；盯市价格前向填充仅用于数据边界。
- 账本恒等：`NAV = cash + Σ(份额×价格) + etf份额×etf价格`。

**一致性校验（`check_ledger_consistency.py`）**——归因验证"双账本 vs 冻结基线"全段偏差：

- 基线（引擎"T 日开盘成交"）在调仓日只计新组合日内段，**漏计旧持仓调仓日开盘前的隔夜跳空**；账本按绝对价格盯市正确计入（实盘持仓确实持有到 t0 开盘才卖出）。**这是模型口径差异，非 bug**。
- 全段偏差 ledger/base−1 = **+14.01%**；逐调仓日累计隔夜跳空（份额模拟，含漂移与停牌阻塞）= **+13.61%**，差 0.40pp 由复利路径解释（20241008 单日 512100 隔夜 +10.0% 在 base 日内 −3.77% 上的复利差异）。

### 3.21 因子增强实验（2026-08-05，factor_lib.py / factor_extend.py）— 负面结论

参照 qlib Alpha158 + GTJA191 从日频 OHLCV/amount 面板构建 **8 个与 BASE 低相关的量价因子**（长周期反转 ret_3m、长窗低波动 vol_60、负偏度 skew_20、量能趋势 amt_ratio_20、量比 vol_ratio、Amihud 非流动性 illiq_20、MAX 彩票效应 max_ret_20、振幅 hl_range_20），方向统一为"高值=好"，结构同 VAL 面板，通过 `engine.score_at/run_backtest` 新增可选参数 `ext_panels`（默认 None，不影响 v1.1.0 基线）。实验流程：单因子方向检验 → 增强打分 IC → Top60 散点 → 阈值重标定回测（注：打分=zscore 均值，因子越多分布越窄 std≈1/√n，0.93 对 12 因子是 ~3.2σ，必须重标定阈值才能公平对比）。

**[0] 单因子方向检验**（winsorize+zscore vs 持有期收益 IC）：3 个因子方向设反，翻转后全正——**illiq_20 IC +0.0836 最强**（非流动性溢价，与 A股小市值效应一致），amt_ratio_20 +0.0479、vol_ratio +0.0406，其余 5 个较弱（0.01~0.03）。

### 3.25 因子加权实验：等权 vs IC 加权 vs ICIR 加权（2026-08-06，score_weight.py）— 负面结论

3.21/3.22 失败诊断为"等权均值稀释强信号"，本节不动因子集合（BASE+VAL 4 因子），只改合成权重，直接验证加权能否提升区分度：

- **ew**（基线）：w_f = 1/n，与 engine.score_at 逐位一致
- **ic**：w_f = max(0, 扩展窗 IC 均值)——弱因子自动降权、负 IC 清零
- **icir**：w_f = max(0, IC均值/IC标准差)——加入稳定性惩罚

无前视：第 t 月权重只用 1..t-1 月 IC（扩展窗），warmup 前 6 个月回落等权；VAL 缺失月自动在可用因子内重归一化。

**[1] 4 因子月度 IC 统计**：ivol +0.1012 / turn +0.0592（ICIR 0.75 最稳）/ VAL +0.0721 / ret_1m +0.0347。
**[2] 权重轨迹**：ic 收敛为 ivol≈0.38-0.42 主导、ret_1m 降至 0.10-0.18；icir 则 turn≈0.36-0.54 主导（因 ICIR 最高）。

| 方案 | 打分 IC | ICIR | Top60 散点 Spearman | 持仓对齐回测（年化/卡玛） |
|---|---|---|---|---|
| ew（基线） | +0.0987 | 0.528 | **+0.0473** | ≥0.93 **14.62% / 0.55** |
| ic | +0.0999（+0.0011） | 0.497 | +0.0119（−0.0353） | ≥1.0 13.07% / 0.54 |
| icir | +0.0917（−0.0070） | 0.537 | +0.0224（−0.0249） | ≥1.0 10.94% / 0.40 |

**结论：IC/ICIR 加权同样无法超越等权**。加权把权重集中到 ivol/turn 后，平均 IC 几乎不动（ic +0.0011），但 **Top60 散点显著恶化（+0.0473→+0.0119）**——高分端排序质量被集中权重破坏，回测端持仓对齐档年化/卡玛全面落后。**等权合成已是该因子集下的近似最优组合**（等权天然兼具分散化与稳定性，单因子 IC 最高的 ivol 与 ICIR 最高的 turn 在等权中已被充分表达）。产出：`results/score_weight.txt/.json`、`score_weight_ic.png`、`score_weight_w.png`、`score_weight_nav.png`。

### 3.26 模型层实验：线性等权 vs Ridge vs GBDT 非线性合成（2026-08-06，score_model.py）— 负面结论

合成层四条路径（补因子/打分层/加权）全部被否后，最后一条技术路径：**不换信息集、只换合成函数**——与基线完全相同的 4 因子 zscore（ret_1m/ivol/turn/VAL），分别用 Ridge（学习型线性、允许负权重）与 HistGradientBoostingRegressor（sklearn 原生 GBDT，非线性+因子交互）替换等权均值：

- 样本：78 个月 × 成分股 = **77,835 行**（标签=fwd 持有期收益，训练窗内 winsorize 1%/99%）
- walk-forward 无前视：第 t 月只用 <t 月样本训练（扩展窗），warmup 18 月；warmup 前基线/模型均回落现金，**同窗对比 60 个月**（2021-07 ~ 2026-07）

**[3] 打分 IC / Top60 散点（同窗）**：

| 合成函数 | 打分 IC | ICIR | 正占比 | Top60 Spearman |
|---|---|---|---|---|
| **ew（基线）** | **+0.1010** | 0.524 | 68% | **+0.0494** |
| ridge | +0.0924（−0.0087） | 0.480 | 65% | −0.0307（−0.080） |
| hgb | +0.0731（−0.0280） | 0.476 | 68% | +0.0064（−0.043） |

**[4] 阈值选股回测（同窗，持仓对齐 ~54.9）**：基线 ≥0.93 **年化 7.81%/卡玛 0.30**（2021-07 起窗口，弱于全窗 14.62% 属窗口效应）；ridge ≥0.0192 年化 1.64%/卡玛 0.06；hgb ≥0.0184 **年化 −4.54%/卡玛 −0.10**（MaxDD 46.5%）。

**结论：模型层在同信息集下显著劣于线性等权**——Ridge 年化 −6.2pp、GBDT −12.4pp，Top60 区分度崩溃（+0.0494→−0.0307/−0.0064）。原因：① 4 因子是极低维、信号已被充分捕获的信息集，等权 zscore 均值已接近最优线性组合，学习型权重在噪声标签（21 日收益 IC 仅 0.03~0.10）上过拟合；② GBDT 的灵活性在 4 特征+强噪声下学到的是样本内伪模式，样本外不泛化（OOS IC 掉到 +0.0731、回测转负）。**模型层要有效，前提是大幅加厚特征集（数百量级，如 qlib Alpha158 全套 + PIT 财务），而那是"换数据/换框架"级别的工程，非本框架增量**。产出：`results/score_model.txt/.json`、`score_model_ic.png`、`score_model_nav.png`。
