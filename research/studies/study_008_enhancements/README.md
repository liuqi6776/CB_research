## 方向1：北向资金 + 两融余额信号（❌ 无效）

**信号构造**（均 T-1 生效）：
- 两融预警：全市场融资余额（SSE+SZSE+BSE 合并）20 日变化率 < 0 → 覆盖率 **40.8%**
- 北向预警：北向资金 20 日累计净买额 < 0（2020-01~2024-08 有效，2024-08 起停止披露）→ 覆盖率 **33.9%**
- 叠加规则：预警时 MA20 仓位 ×0.5

**结果**：
- 全区间：+MA20+两融 = 13.89%（vs MA20 15.72%），MaxDD 仅降 0.14pp，卡玛 0.87→0.77
- 北向子区间：+MA20+北向 = 11.72%（vs 13.54%），MaxDD 降 1.4pp，卡玛 0.88→0.84

**失效原因**：预警覆盖率过高（34-41%）→ 频繁半仓 → 踏空损失（-1.8~-2.0pp）远大于回撤节省（-0.1~-1.4pp）。两融余额下降在牛市中常见（去杠杆回调），北向流出滞后于 MA20 交叉；信号预测力弱于现有 MA20 本身。

## 方向2：层次风险平价 HRP（✅ 温和正增量）

**方法**：调仓日取截至 rb 的过去 120 日个股收益 → LedoitWolf 收缩协方差 → 单连接层次聚类 → 递归二分风险分配（簇间按逆波动率加权）→ 叶子权重。月内固定，与等权同口径（20bps、RS12、MA20）。

**结果**：
- HRP = 15.00% / 0.81 / -18.37% / 卡玛 **0.82**（等权 0.76）
- HRP+MA20 = 15.58% / 0.93 / **-17.34%** / 卡玛 **0.90**（等权+MA20 为 0.87）

**解释**：HRP 利用个股相关性结构，降低高相关簇（同行业/同风格股）的实际集中度；等权组合在行业集中时暴露系统性风险，HRP 无优化目标、无过拟合风险。增量温和但方向正确：收益持平、回撤 -0.7~-1.1pp、卡玛 +0.03~0.06。

## 方向3：行业轮动过滤（❌ 强烈负增量）

**方法**：东财行业静态映射（tushare stock_basic，研究近似），当期中证1000成分股按行业等权合成日收益，过去 63 交易日累计动量排序，仅在前 N 行业成分股池内做 BASE+VAL 因子选股。

**结果**：行业Top3 = -9.7%（MaxDD -51.7%）、Top5 = -4.0%（-60.1%）、Top8 = -2.0%（-63.0%）；叠加 MA20 仍 +2.7%（-37%）。

**失效原因**：
1. **池子收缩**：Top5 行业池内平均仅选出 29.3 只（Top50 饱和度 59%），选择空间被压缩、单票权重翻倍
2. **动量持续性差**：中证1000 小盘行业 3 月动量未来 1 月反转明显（行业轮动速度 > 持仓周期）
3. **行业映射静态**：tushare 当前行业对历史月份有漂移
4. 高换手放大 20bps 成本

### 方向A：主力资金流因子（❌）
mf20 = 过去20日超大单净流入累计 / 同期(超大单+大单)成交额累计，加入五因子选股。月度成分重叠率 66.1%——资金流与现有 ret_1m/换手率量价因子高度重叠，加入后稀释因子纯度：收益 -0.5pp、卡玛 -0.01（带 MA20）。iFinD 侧"主力净流入"概念存在（get_stock_performance 可查），本地 moneyflow1 数据质量优秀（可用率 99.8%+），但**无增量信息**。

### 方向B：宏观 PMI 择时（❌）
iFinD EDB 制造业 PMI 完整月度（2020-01~2026-06），调仓月取上月已发布值（shift(1) 无前视），弱态时 MA20 仓位×0.5。三种弱态定义（PMI<49 / 连续2月<50 / 3MA<50，覆盖率 6%/33%/64%）全部负增量：收益损失 -1.3~-3.9pp 大于回撤节省（极端态还反升 +1.5pp）。与方向1（两融/北向）失败模式完全一致——**MA20 已是有效趋势过滤，任何额外宏观/资金面减仓都是多余，造成踏空**。

### 方向C：质量因子 QMJ（❌ 数据不足 + 负增量）
质量分 = zscore(ROE)+zscore(毛利率)+zscore(净利同比)，ann_date<=rb 最新一期。本地 fina_indicator_cache 仅 1565 只股票、2023-04 起，中证1000 成分覆盖率不足（质量分可用调仓月仅 4/37），因子基本未生效（成分重叠率 89.8%）。即使如此子区间（2023-07~2026-06）仍负增量：Q+MA20 卡玛 0.58 vs 对照 0.67。iFinD 侧 ROE/毛利率/净利增速数据本身可取（报告期），但**本地历史面板缺口导致无法做完整回测**。

### 3.3 止盈止损层：净值回撤止损（risk_control_ddstop.py）

在 HRP+MA20五档底座上叠加组合净值回撤止损（研报"跟踪止损"落地）：
- **失败形态**：回撤 6-8% 清仓 + 创新高才恢复 → 年化仅 1.7%（A 股 2021-2024 长期阴跌中净值长期低于峰值，46% 时间空仓、错过全部反弹）——**峰值锚定恢复 + 清仓 = 灾难**。
- **正确形态**：回撤 ≥ 阈值**降仓至 0.5（不清仓）** + **谷底回升 5% 恢复满仓**（锚定谷底不锚定峰值，阴跌期半仓运行、小反弹及时回补）。

敏感性网格（卡玛，floor 0.5 不清仓）：

| DD阈值＼回升 | 2% | 3% | 5% |
|---|---|---|---|
| 8/12 | 0.31 | 0.43 | 0.45 |
| 9/14 | 0.26 | 0.31 | 0.49 |
| **10/15** | 0.34 | 0.49 | **0.55** |
| **12/18** | 0.37 | 0.47 | **0.54** |
| 基准（无止损） | 0.44 | 0.44 | 0.44 |

回升 5% 全线最优且沿阈值轴平滑（0.45→0.49→0.55→0.54）= 参数高原非孤立尖峰。**最优 +DD(10,15) 谷底回升5%：年化 10.13%、Sharpe 0.71、日频 MaxDD 18.33%、卡玛 0.55**（vs 无止损 11.68%/0.70/26.51%/0.44）——用 1.55pp 年化换 8.2pp 回撤，Sharpe/卡玛双升。

**关键发现：止损层必须配 HRP 权重底座**——同样 DD(10,15)+回升5%，等权底座卡玛 0.41 vs HRP 底座 0.55（HRP 低波组合减少正常波动误触发）。
- **ATR 止损**：组合日频波动大，2-3×ATR 回撤 3-4% 即触发，收益崩；固定回撤阈值优于 ATR。
- **时间止损**：与 RS12 月度动量过滤重叠，只砍利润不降回撤（MaxDD 仅 -2.5pp）。
- **价格型**（入场价/保本）、**布林带/RSI/SAR/MACD**：不适用月度调仓组合（无连续持仓入场价、趋势增强非均值回归）。

### 3.5 最终推荐（真实口径）

**HRP 权重 + MA20五档098 + 净值回撤止损 DD(10,15) 谷底回升5%（降仓至 0.5 不清仓）**
- 年化 **10.13%**、Sharpe **0.71**、日频 MaxDD **18.33%**、卡玛 **0.55**
- 残余简化：ETF 切换按全额换手（turn=1.0）、停牌 ffill 前收延续、涨跌停/ST/退市未建模、月度调仓未计成分内再平衡 \|Δw\| 成本
