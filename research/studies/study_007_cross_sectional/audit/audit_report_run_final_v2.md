# Study 007 回测代码审计报告（run_final_v2.py / config.py / cs_backtest_engine.py）
审计日期：2026-07-17。数据验证基于 D:\iquant_data\data_v2 实际文件。

## 一、确定的漏洞/错误
1. 财务数据严重前视：run_final_v2.py L30 取每票 ann_date 最新一条静态合并到全部历史（L59-62）。缓存 ann_date 范围 20230408-20260421，每票最新值公告日中位数 2025-10-18，100%≥2024-01-01。2023-01 调仓用的 ROE 实为 2025 年才公告的值。
2. 价格未复权：601398.SH 2023-07-14 close=4.87，除息日 2023-07-17 close=4.57 而 pct_chg=0.0000。L41/42/45 全部用 close.pct_change()，除息假跳空污染 ivol、ret_1m、future_ret_20d。
3. 持有期收益与调仓周期错位：固定 20 交易日收益标签 vs 实际月首间隔 15-23 天，错位 -3~+5 天（如 20230103→20230201 实际 16 天，+4 天收益被相邻两期重复计息）。
4. 退市/停牌股收益被静默置零：engine L204-206 NaN 直接 continue，权重按 0 收益计。2023-2024 共 110 只票消失（如 000005.SZ 2024-03-05 后消失）。反转因子偏好暴跌票，最易选中退市整理期股票，最坏结果被系统性剔除。
5. 日净值为线性插值伪造（engine L236-246），夏普/最大回撤/日胜率全部基于伪日频序列：夏普高估、回撤低估、日胜率无意义。
6. winsorize 用全样本分位数（preprocess L77-78），前视。
7. 测试期上选因子（数据窥探）：L103-106 注释自认按 2023-2024 测试期 IC 筛选因子；run_final_v2 从未加载 2020-2022 训练期（L89）。样本外无效。
8. 无预热数据：首个调仓日 20230103 的 factor_score 实际只用（前视的）roe。
9. 成本每月只扣一次单边 0.3%（engine L223，年化 3.6%），与实际双边换手无关，且与 README 自述"年化总成本约 7-8%"矛盾；无滑点、无涨跌停/ST/次新/流动性处理（行业表含 173 只 ST 票）。
10. 89 只无行业映射股票被 groupby('industry') 静默剔除（engine L110）；"行业中性"实为 110 个细分行业各限 1 只的分散约束，max_industry_pct=0.30 语义错误（按行业成分股数量而非组合权重）。

## 二、存疑需验证
- IC 口径本身正确（调仓日截面 Rank IC，24 个月均值 0.0888、19/24=79.17% 与 README 一致），但被前视污染；IC 高+收益负可由 long-only beta + 成本 + 组合受行业约束偏离 top-50 解释，不矛盾。
- run_final_v2 L100-101 单因子 IC 为全面板 pooled Spearman，与 test_factor_validity.py 逐日 IC 口径混用。
- 2020-2025 扩展回测（run_v3.py）共享同一引擎/数据模式，年化 9.78% 同样不可信，需单独审计。
