## 动机

CB 研究归档决议：**月频双低 Top10 风险调整后不优于被动 ETF（511380）** → 主动选债被否。但该决议隐含一个被忽略的价值：**转债在弱市是"低成本股票敞口"**（负转股溢价率 = 折价买股）。若把转债池当作股票池的**下行保护替代**，而非独立 alpha 来源，就形成跨资产轮动：股票强 → 股票增强池；股票弱 → 双低转债池 / 511380 底仓。

- 双低排序与已确认研究口径一致（价格+溢价率），数据可日更（`bond_special_data` 返回最新快照，`bond_market_data` 返回日频价格）。
- ⚠️ 希望转债转股溢价率缺失、浦发转债纯债价值缺失 → 数据质量需过滤（缺失值剔除或降权）。

## 跨资产轮动框架

```
每日信号（沿用同一套 MA20 + 情绪温度计）:
┌──────────────────────────────────────────────┐
│ 中证1000 > MA20 (且情绪不冷)                    │
│   → 股票增强池（chip_momentum + moneyflow 双确认）│
│ 中证1000 < MA20 (或情绪强负面)                  │
│   → 双低转债池（负溢价优先，价格<115 过滤）        │
│   → 极端弱市（中证1000 < MA20 且 < 前低）         │
│     → 511380 ETF 底仓（已确认最优底仓）           │
└──────────────────────────────────────────────┘
```

关键规则：
1. **轮动不等同于"主动选债赚 alpha"**：转债侧默认 511380 底仓，双低池仅作**风险预算再分配**（弱市把股票仓位换成低成本股票敞口），不追求超越 ETF 的风险调整后收益。
2. **负溢价 + 低价过滤**：仅保留 价格<115 且 溢价率<15% 的标的，规避高价高溢价债的回撤风险（牧原 159.6 此类剔除）。
3. **与已归档决议不冲突**：原决议否定"月频双低 Top10 替代 ETF"的主动选债逻辑；本框架只用转债做资产切换载体，不改变"511380 是最优底仓"的结论。

## 避坑清单

- ⚠️ 负溢价转债往往临近转股/强赎，条款风险高，需用已确认的 `unified_pit_engine.py` 做转股价/回售/强赎检查。
- ⚠️ 转债池流动性低于股票池，回测须沿用 20bps 双边 + 5% 成交量上限（已确认工程标准）。
- ⚠️ 数据缺口（溢价率/纯债价值缺失）须显式过滤，避免脏数据进池。
- ⚠️ 框架尚未回测：轮动阈值（115/15%、极端弱市定义）均为先验假设，需 OOS 验证。
